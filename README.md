## 🚀 How to Run & Deploy

### Run Locally:
Simply open **`index.html`** in Chrome, Edge, Brave, or Firefox.

### Deploy to Hosting (e.g. InfinityFree / arjun45.xo.je):
Upload all files (`index.html`, `css/`, `js/`, `assets/`, `resume.pdf`) directly into your hosting folder (`htdocs` / `public_html`).
